# Readable HYRAM GOLF identity

The owner requested a more approachable main logo after the customer-entry UI change. The new mark uses a rounded green H symbol, a restrained gold accent, large Korean `하람골프`, and smaller English `HYRAM GOLF`.

- Replaces ornate cursive lettering and tiny service-tagline text with a Korean-first wordmark.
- Light and dark SVG variants share identical outlined lettering. The result does not depend on device fonts or an external font request.
- Outlines derive from Noto Sans CJK KR Bold by Adobe under SIL OFL 1.1. License is retained in `web/images/brand-font-license.txt`; font source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Korean/NotoSansCJKkr-Bold.otf.
- The H symbol is an original vector drawing. A square SVG version is included for the site icon.
- Repository home, collection, refund and campaign headers use the same identity; the current public template's header is updated by the additive customer-entry script when applied to a confirmed source checkout.
- No person photos, pricing, qualifications, payment, database or domain changes.
